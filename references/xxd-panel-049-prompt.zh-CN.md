# XXD Panel 049｜清新限色木刻生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。
- 也支持 Seedance 5.0 Pro、Nano Banana Pro（Gemini Image Pro）、Nano Banana 2（Gemini Image Flash）或其他兼容位图模型，但只有实际通道具备原图保真、整张成品画幅、目标语言文字，以及连贯壁纸所需多图参考能力时才可使用。
- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

只处理当前新任务明确提供的这一张源照片。私下锁定主体身份、轮廓、比例、方向、动作、明暗分区、关键结构、负形、情绪关系与源图色彩，至少保留三个源图专属线索；不得借用其他输入、旧输出或样张。

## 审美重构

把可识别主体重构为一枚悬浮在温暖纸面上的限色木刻或油毡版画印记。主动删减复杂背景与细碎信息，只保留真正承载识别度和情绪的轮廓、比例、方向、明暗块、关键结构与关系；不是滤镜复刻，而是以可刻、可印的图形语言重新概括。

严格遵循：锁定身份、剪影、方向和情绪关系 → 保留三个线索 → 删除无关背景 → 将主体压缩为可刻轮廓、色块与负形 → 以少量清新哑光油墨手工套印 → 让缺墨、断裂、露纸、错位与磨损边缘按结构自然消散 → 保留大面积温暖留白 → 让克制文案沿轮廓和版画边缘生长。

## 硬性视觉要求

- 保留至少三个源图专属线索，一眼可辨；不得完整复制背景或以统一滤镜代替主动概括。
- 刀痕允许迟疑、粗细不均、转折生硬、发毛、断裂、缺口、错位和不规则留白；色块有干刷、漏印、缺墨与粗颗粒。所有缺陷必须顺应结构，不能是均匀覆盖的做旧贴图。
- 只设一个视觉锚点，位置、尺度、偏置和裁切跟随源图重心与动势；四周保留充分暖纸留白，边缘不完整且自然消散，绝不形成完整矩形框。
- 从源图最有生命力的色彩记忆点提炼少量高明度、低至中饱和、柔和对比的油墨层；可用奶油白、象牙、浅粉、雾绿、浅蓝、嫩黄、淡橙、薄荷、柔珊瑚或浅赭，但不得套固定配色。
- 气质温暖、安静、治愈、轻盈、怀旧而不灰暗；拒绝光滑矢量、卡通描边、脏旧厚重、廉价复古和旅游模板。

## 文案与语言

服从已确认的自动文案、准确自定义文案或无文字模式，以及目标语言／地区。自动文案从主体身份、动作、情绪、状态、地点或隐喻中提炼 1–3 词标题，并配至多一组极短关键词或微注释。标题沿主体轮廓、留白边界、视觉轴或断裂版画边缘形成承托、穿插、错位或呼应；辅助字可用打字机、等宽衬线或档案注释气质，但不得固定年份。准确文案逐字保留；无文字模式不得出现字符、数字、标签或伪文字。

## 模式与验收


拒绝：一键滤镜、完整背景复刻、光滑矢量线、卡通插画、完整矩形边框、均匀做旧层、灰暗脏旧、厚重古董感、通用旅行海报、假批量印刷纹理、logo、水印、色卡、设备样机和无依据事实。

任何硬性条件失败都必须纠正位图资产，不得以程序绘图、SVG、HTML、Canvas、3D 代码或后期文字覆盖伪造成品。
